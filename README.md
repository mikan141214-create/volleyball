# 🏐 Spike Master - バレーボールスパイクフォーム分析アプリ

バレーボール選手のスパイクフォームを動画で分析し、具体的な改善ポイントを提示するWebアプリケーションです。AI姿勢推定技術（MediaPipe Pose）を活用して、ユーザーが自分のフォームを客観的に評価し、効率的に技術向上できる環境を提供します。

## ✨ 主な機能

- **動画アップロード**: スパイク動画をアップロードして自動分析
- **姿勢推定**: MediaPipe Poseによる高精度な姿勢検出
- **フォーム分析**: 踏み込み、打点、ジャンプの各フェーズを評価
- **スコアリング**: 総合スコアとフェーズ別スコアを100点満点で表示
- **改善提案**: 具体的な改善ポイントを自動生成
- **可視化**: グラフやゲージチャートで結果を視覚的に表示
- **履歴管理**: 過去の分析結果を保存し、推移を確認

## 🚀 セットアップ

### 必要な環境

- Python 3.8以上
- pip

### インストール

1. リポジトリをクローン:
```bash
git clone <repository-url>
cd volleyball
```

2. 依存パッケージをインストール:
```bash
pip install -r requirements.txt
```

### ローカルで実行

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` にアクセスしてアプリを使用できます。

## 📦 Streamlit Cloudでデプロイ

### 手順

1. **GitHubリポジトリを準備**
   - このリポジトリをGitHubにプッシュします

2. **Streamlit Cloudにアクセス**
   - [Streamlit Cloud](https://streamlit.io/cloud) にアクセス
   - GitHubアカウントでサインイン

3. **新しいアプリをデプロイ**
   - "New app" をクリック
   - リポジトリを選択: `<your-username>/volleyball`
   - ブランチを選択: `main` または `claude/volleyball-spike-analyzer-aeToU`
   - メインファイルのパス: `app.py`
   - "Deploy!" をクリック

4. **デプロイ完了**
   - 数分でアプリがデプロイされ、公開URLが発行されます
   - URLを共有して、誰でもアクセスできるようになります

### デプロイ時の注意点

- `requirements.txt` がリポジトリに含まれていることを確認してください
- Streamlit Cloudは無料枠で利用できますが、リソース制限があります
- 動画処理は計算量が多いため、長時間の処理には注意が必要です

## 🎥 使い方

1. **動画を準備**
   - スパイク動作を真横から撮影（3〜5メートルの距離）
   - 3〜10秒程度の動画
   - MP4、MOV、AVI形式に対応

2. **動画をアップロード**
   - アプリの「新規分析」タブで動画をアップロード

3. **分析を開始**
   - 「分析を開始」ボタンをクリック
   - 自動的に姿勢推定と分析が実行されます

4. **結果を確認**
   - 「分析結果」タブで総合スコア、フェーズ別スコア、改善ポイントを確認
   - 重要フレーム（踏み込み、最高到達点など）を確認

5. **履歴を管理**
   - 「履歴」タブで過去の分析結果を確認
   - スコアの推移をグラフで確認
